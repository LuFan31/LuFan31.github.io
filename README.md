# Fan Lu Personal Homepage

This repository hosts Fan Lu's personal academic homepage.

## Deployment with GitHub Pages

Recommended repository name:

```text
LuFan31.github.io
```

Upload the following files to the repository root:

```text
index.html
404.html
robots.txt
sitemap.xml
.nojekyll
README.md
```

Then go to:

```text
Settings -> Pages -> Build and deployment
```

Set the publishing source to the `main` branch and root directory.

The expected public URL is:

```text
https://lufan31.github.io/
```

## Search Engine Indexing

After deployment:

1. Add the homepage URL to your GitHub profile.
2. Add the homepage URL to your Google Scholar profile if possible.
3. Submit the site to Google Search Console.
4. Submit the sitemap:

```text
https://lufan31.github.io/sitemap.xml
```

To check indexing status later, search:

```text
site:lufan31.github.io Fan Lu
```

## Updating the Homepage

After the homepage is indexed, you can still update it at any time by editing or replacing `index.html`.
GitHub Pages will publish the updated version automatically after the repository is updated.
Search engines will update their indexed version after they crawl the page again.
